# ComfyComic 路线 M1–M5

保留原漫画编辑器和 AGPL-3.0 许可，使用适配层逐步扩展生成引擎。阶段范围随真实工作流和手机联调结果调整。

| 阶段 | 目标 | 状态/验收重点 |
| --- | --- | --- |
| M1 基础架构 | Flask ComfyUI 适配、可配 API 工作流、隔离 Mock、前端生成与固定画格回填、loopback 开发入口 | 本分支实现；云端自动化与 Mock 验证，真实 GPU 待本机验证 |
| M2 安全本地产品化 | 独立账号/凭据、正式会话与 CSRF、HTTPS/Tailscale 访问控制、真实工作流联调 | 优先阻塞项；认证就绪前禁止将开发入口远程暴露 |
| M3 参考图与角色 | 受保护上传、图生图/局部重绘映射、角色设定与提示词管理、模型能力声明 | 基于用户提供且已验证的 Qwen/Krea2 工作流，不假设通用节点结构 |
| M4 漫画任务与工程 | 持久化任务/取消恢复、页面画格任务参数、跨设备工程同步/备份、批量队列、图库整合 | 保持旧工程导入导出兼容，增加迁移及恢复测试 |
| M5 手机与发布 | 安卓 Chrome 真机交互、性能/显存配置、Windows 启动升级、许可和发布验证 | 长任务/断网恢复、触摸/小屏/工程导出与完整回归 |

## M1 实际交付边界

已实现：独立模块、配置与节点映射校验、HTTP 连通/提交/history/queue/view、会话归属安全图片接口、幂等与超时、显式开发 Mock、可复用原漫画工作区的新入口、基础生成状态/预览/回填和下载。

未实现：独立正式远程认证、Tailscale Host 支持、真实 GPU 验证、真实 Qwen/Krea2 预设、参考图/图生图/重绘、WebSocket 精确进度、任务持久化/刷新恢复/取消、ComfyUI 图库索引、多输出图选择、独立工作流任务参数保存到画格。M1 只把结果图保存到原工程中，Comfy 参数当前保存在页面内存中。

## M2 推荐先后顺序

1. 用户提供真实 API JSON，完成 Windows 4070 Super 实测：节点/模型校验、尺寸和 seed、错误诊断、超时参数。
2. 实现与 NovelAI 解耦的正式本地认证、凭据初始化与恢复、会话撤销/持久化、权限隔离，补充安全测试。
3. 制定 HTTPS/Tailscale 明确 Host、Origin 与实际 peer 策略，验证反向代理信任边界，绝不把开发 loopback 作为远程认证。
4. 任务持久化、重连/刷新恢复、取消与上游队列一致性；将 Comfy 工作流和参数与画格任务关联保存，使用兼容的可选扩展字段。
5. 安卓真机验收：切换页面/画格、后台挂起/断网、触摸、预览下载、工程备份与重新导入。
